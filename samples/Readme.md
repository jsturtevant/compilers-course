# Cool Language Samples

Sample programs from Stanford's Compilers course materials.

**Source:** https://courses.edx.org/asset-v1:StanfordOnline+SOE.YCSCS1+1T2020+type@asset+block@student-dist.tar.gz

## Programs

| File | Description |
|------|-------------|
| `arith.cl` | Tests various aspects of arithmetic in Cool |
| `atoi.cl` | Implementation of C's atoi - converts String to Int |
| `atoi_test.cl` | Example program using atoi.cl |
| `book_list.cl` | Illustrates inheritance, static dispatch, and case statements |
| `cells.cl` | Models a one-dimensional cellular automaton |
| `complex.cl` | Checks = operator and cumulative method call effects |
| `cool.cl` | Short and obscure program |
| `graph.cl` | Reads weighted-directed graphs from stdin |
| `g1.graph` | Sample input for graph.cl |
| `hairyscary.cl` | Exercises obscure language features |
| `hello_world.cl` | The classic first program |
| `io.cl` | Shows how to use the IO class |
| `lam.cl` | Lambda calculus example |
| `life.cl` | The classic Game of Life |
| `list.cl` | Simple list data type for integers |
| `new_complex.cl` | Complex number operations |
| `palindrome.cl` | Recognizes palindromes |
| `primes.cl` | Unusual prime number generator |
| `sort_list.cl` | Sorting lists of integers |
